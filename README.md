# Satan's Lil Helper
A roguelike game for gaming gamily (down some stairs, preferrably).


## Setup
### Windows
1. Install [Python](https://www.python.org/downloads/windows/)
   - Make sure to add it to the path
1. Either clone this repository or download the zip of the code.
1. Open a Windows PowerShell or terminal in the folder with `main.py` by holding `ctrl` and `shift` and right clicking.
1. Create a Python virtual environment using `python -m venv .venv`
1. Activate your new virtual environment with `. .venv\Scripts\Activate`
1. Install the requirements with `pip install -U -r requirements.txt`
1. Run the game with `python main.py`
